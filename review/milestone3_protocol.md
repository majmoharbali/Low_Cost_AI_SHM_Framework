# KW51 environmental reference replay

This analysis plan was committed before fitting or viewing detector outcomes. It uses the checksum-verified [KW51 tracked modal archive](https://zenodo.org/records/3745914) and the [Milestone 2 chronology](milestone2_kw51.md). The estimand is the change in reference alarm behaviour and the response around the retrofit when conditioning these published features on temperature.

## Chronology and feature eligibility

- Allocate the 5,424 scheduled reference hours in chronological order. Cut after floor(0.6 × 5,424) and floor(0.8 × 5,424) hours. Make the cuts before filtering for missing values. Purge the last 24 hours from the fitting and calibration blocks so the next block begins after one full daily cycle. This limits direct adjacency, while longer serial dependence can remain. Archive slots represent distinct hourly acquisitions. Both boundary dates from the data audit stay excluded.
- Use Vliet air temperature (`tVL`) as the primary environmental predictor. The data audit established uninterrupted reference coverage for this off-site proxy. Select the fixed mode panel by requiring at least 90% joint availability with `tVL` in the purged fitting block, using scheduled hours as the denominator. Keep original mode IDs. Stop if no modes qualify or if fewer than 200 common fitting or calibration hours remain.
- Use complete fitting rows for all three primary models. Keep missing scheduled hours in evaluation. For conditioned models, require all panel frequencies and temperature to be available and abstain outside the inclusive fitting range of temperature. The unconditioned model requires only the panel. Use common supported hours for the primary comparison and report each model's operating coverage as well. Record missing panel, missing temperature and out-of-range counts, including overlaps where applicable.

## Fit and freeze

1. Predict each selected frequency with its fitting mean, a linear regression on centred and scaled temperature, or a cubic B-spline with interior knots at the fitting temperature quartiles. Penalise squared second differences of spline coefficients using the objective mean squared error plus the penalty. Tune the penalty over 0.00001, 0.001, 0.1 and 1 using expanding fits and validation at the 40%, 60% and 80% cuts of the scheduled fitting block. Purge 24 training hours before each validation, stop if a fold has fewer than 72 supported validation rows, and average the fold errors standardised by each training mode's standard deviation. Recompute knots and standardisation inside each fold. Break ties toward the larger penalty. [SciPy B-spline design matrix](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.BSpline.design_matrix.html).
2. Estimate the covariance of each model's frequency residuals from its fitting rows. Use a fixed 5% shrinkage toward its diagonal and compute squared Mahalanobis distances. Save each model's parameters and the selected modes, covariance and temperature support. Report fitting-only temperature and residual autocorrelations at 1, 24 and 168 hours to describe dependence.
3. Use the same supported complete calibration hours for the three models. Set each cutoff to the empirical 0.99 quantile using the `higher` order statistic. Record the threshold and calibration denominator in a frozen JSON artifact before evaluating later blocks. A flag requires a strict exceedance in two consecutive valid scheduled hours. Count an episode at the second exceedance, and keep it active until an invalid hour, a time gap, a non-exceedance or a change of analysis period. [NumPy quantile methods](https://numpy.org/doc/stable/reference/generated/numpy.quantile.html).

## Evaluation and sensitivity

For each reference-test, retrofit and post-retrofit block, report coverage, fraction of scored hours exceeding the threshold, persisted alarm hours divided by scored and scheduled hours, and episodes per 30 scheduled days. Reset persistence at each block boundary. Compare common and operating eligibility separately. Report retrofit and post-retrofit outcomes without inventing a damage onset time.

Use 2,000 seeded moving-block bootstrap draws of seven-day blocks for the primary reference-test episode rate and paired rate differences. Resample the already evaluated episode onsets by scheduled hour so blocks share the same indices across models and missing hours remain in exposure. Seven days covers daily and weekly operation cycles, while the short test period and longer dependence can leave the intervals unstable. Treat these as descriptive uncertainty conditional on the frozen fit and threshold, and retain sparse-event limitations.

For a secondary check, compare the two temperature proxies using linear compensation on the same paired fitting and calibration rows, the primary mode panel and joint in-range support. Repeat the held-out comparison on hours with both temperatures and the complete panel. Return an unavailable sensitivity if the paired fitting or supported calibration sample is below 200 hours. This checks proxy choice with the sample held fixed.

KW51 hourly estimates were tracked by the provider across the campaign. The replay tests a detector on these precomputed features. Modes can differ in availability, the arch instrumentation changes near the end of the retrofit, and the reference period may contain defects. The experiment cannot isolate causal retrofit effects or test channel reduction from the processed series.
